B.5. Regresión múltiple

Se ajustó un modelo de regresión múltiple utilizando los 731 registros de day.csv. La variable respuesta fue cnt y las variables explicativas fueron temp, atemp, hum y windspeed, manteniendo la escala normalizada del dataset.

Estimación por mínimos cuadrados

Se construyó la matriz X de dimensión 731 x 5, con una columna de unos y las cuatro variables explicativas. Se resolvieron las ecuaciones normales:

(XᵀX)β̂ = Xᵀy, equivalentes a β̂ = (XᵀX)⁻¹Xᵀy.

La resolución se realizó mediante numpy.linalg.solve. Como en B.2, los resultados se contrastaron con statsmodels:

b0 (intercepto): fórmulas = 3860,3685; statsmodels = 3860,3685.
b1 (temp): fórmulas = 2111,8136; statsmodels = 2111,8136.
b2 (atemp): fórmulas = 5139,1524; statsmodels = 5139,1524.
b3 (hum): fórmulas = -3149,1098; statsmodels = -3149,1098.
b4 (windspeed): fórmulas = -4528,6748; statsmodels = -4528,6748.

Los coeficientes coinciden dentro de la precisión numérica, con una diferencia máxima de 2.11e-09. También coinciden, al redondear a cuatro decimales, con la solución de mínimos cuadrados usada como referencia en A.3.

Modelo final

cnt_estimado = 3860,3685 + 2111,8136·temp + 5139,1524·atemp -3149,1098·hum -4528,6748·windspeed.

Cálculo del coeficiente de determinación

Usando la notación de B.1:
SCE = sum(yi - ŷi)² = 1468850901,4569.
STC = sum(yi - ȳ)² = 2739535392,0465.
R² = 1 - SCE/STC = 0,463832.

Comparación con el modelo simple de B.2

En B.2 se seleccionó atemp, con el modelo cnt_estimado = 945,8240 + 7501,8339·atemp. Para comparar se aplicó literalmente la fórmula de R² ajustado del enunciado:

R² ajustado = 1 - (1 - R²)·(n - k)/(n - k - 1).

Aquí n = 731 y k es el número de variables explicativas, sin contar el intercepto. Para el modelo simple k = 1 y para el múltiple k = 4.

Simple (atemp): R² = 0,398244; R² ajustado según consigna = 0,397418.
Múltiple: R² = 0,463832; R² ajustado según consigna = 0,463094.

Conclusión

El modelo múltiple explica el 46,38% de la variabilidad observada, frente al 39,82% del modelo simple, una diferencia de 6,56 puntos porcentuales. También supera su R² ajustado. Por lo tanto, incluir conjuntamente las cuatro variables mejora el ajuste a estos datos. Esto no implica causalidad ni garantiza una mejora predictiva en días nuevos.

Nota sobre R² ajustado: la fórmula estándar utiliza n-1 en el numerador, en lugar de n-k. Con ella se obtiene 0,460878 para el múltiple y 0,397418 para el simple. Estos valores coinciden con rsquared_adj de statsmodels y la conclusión se mantiene. Los resultados anteriores se identifican como "según consigna" para distinguir ambas fórmulas.
